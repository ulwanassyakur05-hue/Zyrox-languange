Quick guide to the current V3.4 browser runtime.

Getting started

Open Interpreter, write one command per line, then press RUN CODE. The runtime processes Zyrox statements in order and prints results to the output console.

Print.line("Hello from Zyrox!")

Output commands

Print.true("text") displays text. Print.false("text") intentionally produces no output. Print.line(value) prints a value and Print.number(value) prints a numeric value.

Variables & values

Var.set("name", "Ulwan")
Print.line(Var.get("name"))
Math.add(10, 5)
String.upper("zyrox")

Values may be quoted strings, numbers, booleans, or supported nested calls.

Arrays & utilities

Array.create("items")
Array.push("items", "One")
Print.line(Array.get("items", 0))
Random.int(1, 10)
Date.today()

Arrays use zero-based indexes. Random.int includes both endpoints.

Syntax rules

  • Use double quotes for strings.
  • Separate statements with a newline.
  • Use // or # for single-line comments.
  • Command names are case-insensitive in the runtime.
  • Division by zero and invalid arguments return a Zyrox error.

Compatibility & safety

V3.4 preserves the confirmed Print.true and Print.false behavior from the earlier project. Additional commands listed as EXPERIMENTAL are new runtime features, not retroactively declared as original creator-approved core syntax. This interpreter does not use JavaScript eval and cannot read arbitrary device files. File.save creates a downloadable file through the browser.
