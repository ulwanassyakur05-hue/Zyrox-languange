Tentang proyek

Bahasa yang dibangun lewat eksperimen.

Zyrox adalah proyek konseptual untuk merancang syntax, aturan, dan kemungkinan interpreter. V3.2 membawa interpreter browser yang dapat menjalankan subset command Zyrox yang didokumentasikan di bawah. Sintaks khusus tetap dipertahankan; fitur tambahan diberi status eksperimental.

⌘

Syntax eksperimental

Merancang cara baru untuk menulis perintah, kondisi, input, dan output.

⌁

Test & research

Menguji konsistensi syntax dan mencari bagian yang masih membingungkan.

◈

Interpreter V3.2

Menguji command yang benar-benar berjalan dengan parser sederhana tanpa eval JavaScript.

Mega Syntax Registry

Command reference.

Core syntax yang ditetapkan creator dipertahankan. Command tambahan adalah API V3.2 eksperimental dan hanya command yang diimplementasikan yang bisa dieksekusi.

Core / Print

Print.false("teks")

Comment: # text or // text

Creator-defined semantics remain special: Print.true() displays its argument and Print.false() does not display it, following the current Zyrox core definition. Use Print.line() for conventional output. The special (#..."True-text) / (#..."False-Text) syntax is also recognized for simple text.
